# Backend plan and source material

This folder preserves the supplied technical plan and its draft source documents. It is a reference bundle, not a backend implementation.

## Contents

- `source-materials/MerchIO — Backend Architecture & Implementation Plan (v2).md` — proposed backend technology, module layout, API, sync, and delivery approach.
- `source-materials/MerchIO — Product Requirements Document (PRD).md` and `... Software Requirements Specification (SRS) Core Modules.md` — draft product and functional requirements.
- `source-materials/MerchIO — Architecture Document.md` — draft architecture, runtime flows, and decisions.
- `source-materials/MerchIO — Security Measures.md` and `... Threat Model v0.1 and Workshop Pack.md` — proposed controls and threat-model seeds.
- `source-materials/MerchIO_Readiness_Audit.md` and `.html` — supplied readiness findings.
- `source-materials/MerchIO — Project Documentation Plan.md` — source document governance and status.
- `source-materials/cursorsecurityrules.md` — a conveniently labeled copy of the supplied security rules; the two original numbered copies are also preserved.

The original numbered security-rules files were byte-identical when packaged. The originals identify the main planning documents as drafts or in review. They are preserved as supplied; no document is represented as approved. The desktop and mobile source archives and their extracted source trees are preserved under `src/frontend/desktop/` and `src/frontend/mobile/`.
